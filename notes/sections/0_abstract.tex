We propose a freshness-bounded distributed shared memory (DSM) for warehouse-scale multi-agent systems that exposes tile-level reads and writes and supports atomic task claims. The DSM combines Conflict-Free Replicated Data Type (CRDT) based merges with an owner–halo gossip protocol to bound the age of information, reduce task propagation time, and lower tail completion time compared to a centralized memory server at equal bandwidth, independent of per-agent control policies. Our design is guided by stigmergic communication and is locality driven, time constrained, and merge safe, with explicit token budgets to enforce bandwidth discipline. We position swarm intelligence as the collective context layer and deep neural networks as per-agent cognition, and show that a freshness-safe, conflict-free, bandwidth-bounded memory enables the swarm to behave coherently as one system. Ablations compare centralized versus DSM owner coordination systems on propagation, completion time and stability. We assess halo gossip’s impact on border oscillations and cross-region propagation, and evaluate merge operators for stability under high-density workloads. This work reframes the environment’s global memory as a systems advance for embodied multi-agent coordination, turning simple, local behaviors into scalable, robust collective performance.
